A classic 2D tower defense game built with **C++17** and **SFML 3.0.2**, featuring multiple maps, a variety of enemies and towers, upgrade mechanics, and a polished menu system.

---

## 🎮 Features

- **4 Unique Maps** with complex, hand‑crafted waypoint paths  
  `Forest Spiral` · `Desert Maze` · `Mountain Labyrinth` · `Ice Vortex`
- **6 Enemy Types**  
  Basic, Fast, Tank, Flying, Healer, Boss – each with distinct stats and behaviour
- **5 Tower Types**  
  Cannon · Sniper · Machine Gun · Slow · Tesla  
  All towers are upgradable (3 levels)
- **5 Waves** per map with increasing difficulty  
  Bosses, healers, and flying enemies appear in later waves
- **Interactive UI**  
  - Tower shop with colour‑coded entries  
  - LIVES · GOLD · WAVE counters  
  - Tower placement preview and range indicators  
  - Detailed in‑game controls and instructions
- **Main Menu**  
  - Title screen with decorative visuals  
  - Map selection with difficulty labels and descriptions  
  - Keyboard navigation (Arrow, Enter, Esc)
- **Pause & Game Over / Victory screens**  
  Overlays with restart and return‑to‑menu options
- **Operator Overloading Demo** (Vector2D struct)
- **Robust game logic** – flying enemies leave the map and cost lives, healers support allies, slow towers apply movement penalties
